# DOM Projects 🧩

A collection of **5 mini projects** I built while practicing **DOM Manipulation with JavaScript**.

The main goal of this repository is to improve my **JavaScript DOM basics and fundamentals** by creating small, interactive features.

## 📂 Projects

### 1. Add Friend Feature
A simple interactive feature where clicking the same button toggles between adding and removing a friend.

**Concepts practiced:**
- DOM selection
- Event listeners
- Click events
- Changing text and styles dynamically

### 2. Instagram Love Button ❤️
A mini Instagram-like feature where clicking on an image triggers a love/like interaction.

**Concepts practiced:**
- Click events
- DOM manipulation
- CSS class manipulation
- Dynamic UI changes

### 3. Custom Cursor 🖱️
A custom cursor effect that follows the user's mouse movement.

**Concepts practiced:**
- Mouse events
- `mousemove`
- DOM positioning
- Dynamic styles

### 4. Multiple Image Hovering Animation 🖼️
An interactive image effect where different images appear or animate based on mouse hovering.

**Concepts practiced:**
- Mouse events
- Hover interactions
- DOM manipulation
- Dynamic positioning
- CSS animations

### 5. Instagram Story Feature 📸
A mini Instagram-style story feature where users can interact with story previews and view the selected story.

**Concepts practiced:**
- DOM manipulation
- Click events
- Arrays and data handling
- Dynamic content
- Timers and UI updates

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- DOM Manipulation

This repository is part of my **JavaScript learning journey**. I am building these mini projects to strengthen my understanding of DOM manipulation and JavaScript fundamentals through practical implementation.

More projects and improvements will be added as I continue learning.
